# Validador de Largo de Contraseña

### 📝 Descripción
Validador de seguridad para contraseñas. Verifica la extensión mínima de caracteres y la integridad de la entrada mediante lógica condicional, asegurando que las credenciales cumplan con requisitos básicos de seguridad.

### 🚀 Tecnologías utilizadas
* **Conceptos:** Introducción a la ciberseguridad, manejo de strings (cadenas de texto) y funciones de medición de longitud de datos.
